# Your Agent in One Emoji

## The emoji

🐜

## Why this emoji

An ant reads instantly — one glance and you know it — yet it says something
specific about how an AI agent actually works, not just what it is.

- **Tireless and never sleeps.** An ant colony works around the clock, and so
  does an agent: it keeps going through long task lists long after a human
  would stop for the day.
- **Loops until done.** An ant carries a crumb, drops it, picks it up again,
  finds a new route — the same patient retry-and-reroute loop an agent runs
  through until a task is finished.
- **Small, but carries many times its weight.** One small glyph, one small
  program — yet it can lift a workload far bigger than itself.
- **A worker, not a face.** It stays far from the obvious robot (🤖) and
  smiley (🙂) picks: it captures the agent's *character* — diligent,
  relentless, quietly carrying the load — rather than its shape.

## How to run

```sh
python3 main.py
```

This writes the single emoji to `/output/entry.txt` (or to
`./output/entry.txt` when `/output` is not writable, e.g. during local
testing). The output file contains exactly one character: 🐜
